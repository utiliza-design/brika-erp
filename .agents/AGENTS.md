# Instrucciones para agentes de IA en este proyecto

Antes de realizar cualquier tarea en este repositorio, lee completo specify/constitution.md — contiene las reglas fijas del proyecto (stack técnico, flujo de Git, manejo de credenciales, e interacción con herramientas) y son de cumplimiento obligatorio, sin excepciones.

Si specify/ tiene además archivos en specify/specs/, revisa si alguno es relevante para la tarea que se te pide antes de empezar.

Ante cualquier duda sobre si una acción está permitida por las reglas de constitution.md, pregunta a Stanley antes de proceder — no asumas ni interpretes de forma flexible.
